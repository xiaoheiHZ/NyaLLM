多窗调度 · 后台管理

斜切任务栏、双窗分屏与横向循环布局

左侧 3D 斜切任务卡可一眼辨别「已完成 / 后台推理中 / 等待确认」状态；把卡片拖入主区即可组合为可调分割线的双窗分屏，多窗口支持并行 SSE 流式输出。

  • 顶栏「⋯」一键新开独立窗口、双窗分组、独占全屏或收起到后台窗口；
  • 「后台窗口」面板支持统一查看、快速切回或一键安全清理且保留草稿；
  • 「设置 → 窗口布局」支持在多任务斜切栏与横向循环模式之间自由切换。
Agent 工具 · 模型产物

内置本地工具、PNG 绘图、MCP 与 SKILL.md

模型不止输出文字，还能直接调用工具并在对话内展示可预览、可保存的文档与 PNG 绘图产物，每一步活动参数均可展开审计。

  • 完整支持 MCP Streamable HTTP（JSON/SSE），调用前强制弹出参数确认；
  • 支持导入 SKILL.md 技能文件并按对话精细启用；
  • 内置计算器、时间工具、独立只读分析子 Agent、文档/表格编辑与「浏览器与 SSH」快捷拉起。
联网检索 · 推理控制

DeepSeek + Tavily 双搜索引擎与思考强度滑块

联网搜索同时支持 DeepSeek 与 Tavily 两套引擎，各自独立保存 API Key 与返回条数（1–10 条）。Tavily 支持深入搜索，并在读取公开网页前逐次请求你的确认。

  • 官方思考链默认自动展示，可按需折叠或切回隐藏；
  • 支持单段对话内用滑块在「自动 / 轻量 / 标准 / 深入」间微调思考强度；
  • 每条回复底部实时呈现输入/输出 Token 数与 token/s 生成速度。
无障碍能力 · 硬安全护栏

看得懂屏幕、守得住底线的安卓手机助手

开启系统无障碍服务后，仅在你主动下发任务时按需读取前台节点与截图（Android 11+），日常零后台事件采集。

  • 密码脱敏：密码与验证码输入框自动替换为 [密码已隐藏]，硬编码禁止代填；
  • 高危拦截：支付、转账、删除、发送、权限授予及坐标点击必弹二次确认浮层；
  • 自我隔离：代码层禁止操控 NyaLLM 自身的设置页与授权页。
记忆与分支 · 多模态

对话分支新窗、本机持久记忆与全量备份

任意单条回复都可以一键「分支到新窗口」，方便用不同模型或不同提示词并行对比结果。

  • 初次回复后自动总结对话标题，保持侧栏清爽；
  • 支持编辑本机持久记忆并按相关性自动摘录历史上下文；
  • 支持图片（JPEG/PNG/WebP）、PDF（≤8 页转图或原生文件）、DOCX 与 UTF-8 文本预览保存，以及 ZIP 全量本地备份。
