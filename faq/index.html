NyaLLM 快速上手指南与常见问题（FAQ）

汇集安装升级、API Key 隐私保护、本地 Ollama 局域网连接、MCP 与 SKILL.md 技能、手机助手安全护栏以及备份恢复的高频问题解答。

1. NyaLLM 是免费软件吗？支持哪些安卓系统版本？

NyaLLM 客户端本身完全免费下载使用，采用 BYOK（自带模型 API Key）或连接本地 Ollama 模型的方式运行。安装包仅 7.61 MB，支持 Android 8.0（API 26）及以上系统；在 Android 12 及以上设备上会自动启用系统级实时模糊渲染。

2. 老版本升级到 NyaLLM 0.9.1 需要卸载重装吗？

不需要。0.9.1 延续与 0.4.x – 0.9.0 完全一致的官方签名证书，直接从 下载中心 获取 APK 覆盖安装即可完整保留对话、本机记忆、自定义背景图、附件与所有服务商凭据。旧版的「隐藏思考」会自动迁移为「自动显示」，也可随时切回。

3. 我的 API Key 和聊天记录安全吗？会上传到第三方服务器吗？

所有 API Key、MCP Token、聊天记录与本机记忆都仅保存在你的手机本机，请求直接发往你在服务商页面配置的目标接口，不经过任何作者自建中转服务器。更换自定义接口地址时还会自动隔离旧凭据与自定义请求头，避免误发密钥。

4. 怎么用 NyaLLM 连接电脑上的 Ollama 本地大模型？

在运行 Ollama 的电脑上设置环境变量 OLLAMA_HOST=0.0.0.0:11434 并重启 Ollama（确保防火墙放行 11434 端口）。手机连入同一 Wi-Fi 后，打开 NyaLLM 的「Ollama · 本地」服务商页面填入 http://电脑局域网IP:11434（留空 API Key），点「拉取模型」即会通过 /api/tags 自动发现已安装的本地模型。

5. 开启无障碍「手机助手」会不会泄露密码或误触发支付？

不会。手机助手平时零事件记录，仅在你主动发起任务时读取当前屏幕；客户端内置三层硬安全护栏：密码与验证码输入框自动脱敏为 [密码已隐藏] 并禁止代填；支付、转账、删除、发送、权限授予及坐标点击全部强制弹出二次确认浮层；硬编码禁止操控 NyaLLM 自身的设置与授权页。

6. 如何在 NyaLLM 中配置 MCP 工具、SKILL.md 和联网搜索？

在设置中填入支持 Streamable HTTP（JSON/SSE）协议的 MCP 服务器地址即可接入外部工具，每次调用前都会弹出参数确认框；支持导入 SKILL.md 技能并在对话底栏「工具」菜单中按会话启用。联网搜索支持同时保存 DeepSeek 与 Tavily 两套 Key，可在对话底栏一键切换。

7. 换手机时如何迁移全部聊天记录与配置？如何支持作者？

在应用内使用 ZIP 全量本地备份功能即可导出消息、窗口布局、自定义背景图、附件与模型产物并在新设备一键还原。如果你喜欢 NyaLLM，欢迎前往官方爱发电主页 ifdian.net/a/NyaLLM 支持独立开发者小黑子打篮球hz，或在 GitHub 仓库 反馈建议。
