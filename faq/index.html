1. NyaLLM 1.0.2 支持哪些安卓版本？为什么采用 targetSdkVersion 28？

NyaLLM 客户端完全免费下载使用，体积仅 7.87 MB，支持 Android 8.0（API 26）及以上并在 Android 15 实机通过完整验收；Android 12+ 自动启用全屏轻高斯模糊。采用 targetSdkVersion 28 是为了在免 Root 情况下合法开放应用私有目录的 Linux exec 可执行权限，确保 Alpine / Ubuntu / Debian / Arch 官方 RootFS 内的命令行与工具链直接正常运行。

2. 老版本升级到 NyaLLM 1.0.2 需要卸载重装吗？

不需要。1.0.2 延续与 0.4.x – 1.0.1 完全一致的官方签名证书，直接从 下载中心 获取 APK 覆盖安装即可完整保留对话、项目、本机记忆、自定义背景图、附件与所有服务商凭据。

3. 什么是「工作极简模式」？如何避免日常打招呼误触发联网搜索？

工作模式默认启用极简模式（可在欢迎页、+ 菜单与设置中一键开关）：首轮仅发送 nya_linux_exec 与 nya_load_tools 及精简目录表，模型只在真正需要时才动态挂载隐私浏览器、搜索、图表或文件工具，大幅节省输入 Token。同时 1.0.2 将工具模式下的联网搜索改为按需调用 nya_web_search，日常问候（如「你好」「现在呢」）或本地终端命令不再无故触发搜索。

4. 我的 API Key 和聊天记录安全吗？隐私浏览器会留痕吗？

所有 API Key、MCP Token、聊天记录、项目与本机记忆都仅保存在你的手机本机，请求直连你配置的目标接口，不经过任何作者自建中转服务器。内置隐私 Agent 浏览器嵌在主视图层，系统最近任务列表完全不可见，隐藏后自动收起为右下角不挡字紧凑胶囊 [ ▢ 浏览器 × ]；临时对话模式更不落盘并自动屏蔽本机记忆。

5. 怎么用 NyaLLM 连接电脑上的 Ollama 本地大模型？

在运行 Ollama 的电脑上设置环境变量 OLLAMA_HOST=0.0.0.0:11434 并重启 Ollama（确保防火墙放行 11434 端口）。手机连入同一 Wi-Fi 后，打开 NyaLLM 的「Ollama · 本地」服务商页面填入 http://电脑局域网IP:11434（留空 API Key），点「拉取模型」即会通过 /api/tags 自动发现已安装的本地模型。

6. 开启无障碍「手机助手」会不会泄露密码或误触发支付？

不会。手机助手平时零事件记录，仅在你主动发起任务时读取当前屏幕；客户端内置三层硬安全护栏：密码与验证码输入框自动脱敏为 [密码已隐藏] 并禁止代填；支付、转账、删除、发送、权限授予及坐标点击全部强制弹出二次确认浮层；硬编码禁止操控 NyaLLM 自身的设置与授权页。

7. 换手机时如何迁移全部聊天记录与配置？如何支持作者？

在应用内使用 ZIP 全量本地备份功能即可导出消息、窗口布局、项目、自定义背景图、附件与模型产物并在新设备一键还原。如果你喜欢 NyaLLM，欢迎前往官方爱发电主页 ifdian.net/a/NyaLLM 支持独立开发者小黑子打篮球hz，或在 GitHub 仓库 反馈建议。
