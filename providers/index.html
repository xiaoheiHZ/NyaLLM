局域网连接电脑 Ollama 简明步骤

1. 在电脑端监听局域网地址

在运行 Ollama 的电脑上设置环境变量 OLLAMA_HOST=0.0.0.0:11434 并重启 Ollama 服务，确认至少已拉取一个模型（例如 ollama pull qwen3:8b），同时在系统防火墙放行 11434 端口。

2. 在 NyaLLM 中无 Key 拉取模型

确保手机与电脑处于同一 Wi-Fi，在 NyaLLM 的「Ollama · 本地」服务商页面将地址改为 http://电脑局域网IP:11434，保持 API Key 留空，点击「拉取模型」即可通过 /api/tags 自动导入所有模型。
